# ADDITIONAL VALIDATION ANALYSIS OF THE α9α10 nAChR PAM BINDING-SITE HYPOTHESIS

## OVERALL INSTRUCTION

I have already completed substantial computational work for the α9α10 nicotinic acetylcholine receptor (nAChR) positive allosteric modulator (PAM) project, including:

* AlphaFold 3 (AF3) protein–ligand cofolding
* Boltz-2 protein–ligand cofolding
* Boltz-2 affinity prediction
* molecular docking
* additional structural and computational analyses
* an established in-house computational protocol.

**Do not redesign, replace, or unnecessarily repeat this existing workflow.**

Instead, perform a **separate additional analysis specifically designed to validate, challenge, and strengthen the existing proposed PAM binding-site hypothesis**.

The objective is to determine whether the proposed site:

1. is structurally reproducible,
2. remains plausible under independent/site-conditioned analysis,
3. provides a chemically reasonable PAM binding mode,
4. explains the experimentally observed SAR,
5. distinguishes active from inactive analogs,
6. generates reproducible residue-level predictions,
7. survives comparison against competing binding-site hypotheses, and
8. ultimately produces experimentally testable predictions for mutagenesis.

The final experimental validation will be performed through **receptor mutagenesis and functional testing**.

---

# PROJECT CONTEXT

The target is the α9α10 nAChR.

There is currently:

* no experimentally determined full-length α9α10 receptor structure,
* no experimentally determined α9α10 PAM-bound structure,
* no experimentally established α9α10 PAM binding site,
* no experimentally defined residue-level PAM interaction map.

The receptor will be considered primarily in the two reported stoichiometric arrangements:

* `(α9)₂(α10)₃`
* `(α9)₃(α10)₂`

The PAM dataset contains approximately 30 experimentally characterized compounds:

* 7 active compounds,
* 23 inactive compounds,
* one highly active nanomolar PAM,
* one near-active compound,
* ascorbic acid as the reference compound,
* ascorbic-acid-derived analogs.

The experimental SAR therefore provides an important ligand-side constraint on the proposed binding hypothesis.

# 3. EXPLICIT SITEAF3 ANALYSIS BASED ON THE PNAS STUDY

## CRITICAL REQUIREMENT

Explicitly incorporate **SiteAF3**, the site-specific AF3 approach described in the PNAS paper:

**Tang and Wang, “Accurate site-specific folding via conditional diffusion based on AlphaFold3,” PNAS, DOI: 10.1073/pnas.2521048122.**

Do not describe SiteAF3 merely as a generic pocket predictor.

The purpose of SiteAF3 in this project is:

> **site-conditioned testing of candidate α9α10 PAM binding-site hypotheses.**

SiteAF3 should therefore be used **after candidate sites have been generated from the existing AF3/Boltz-2 and structural analyses**, rather than being used to blindly confirm a preselected site.

Use the existing AF3/Boltz-2 results and independent pocket analysis to define a set of candidate sites.

# 3B. SiteAF3 SITE-CONDITIONED MODELING

For each serious candidate binding site:

1. use the appropriate α9α10 receptor model,
2. define the candidate site using the relevant pocket/site information,
3. run SiteAF3 using the PAM ligand,
4. generate multiple predictions where feasible,
5. evaluate whether SiteAF3 can generate a coherent ligand–receptor complex at that site.

Perform this for the strongest candidate site and credible competing sites.

Use the same ligand panel where computationally feasible, prioritizing:

* the nanomolar PAM,
* the near-active PAM,
* representative active compounds,
* representative inactive analogs,
* structurally informative activity-cliff pairs.

---

# 3C. SITEAF3 IS NOT THE FINAL PROOF OF THE SITE

Do not conclude:

Instead ask:

> **When the candidate site is explicitly conditioned, does SiteAF3 generate chemically and structurally coherent complexes that are consistent with the existing AF3/Boltz-2 predictions and experimental SAR?**

This distinction is mandatory.

# 3E. SITEAF3 COMPETING-SITE TEST

# 4. BOLTZ-2 LIGAND-CONDITIONED CONSENSUS ANALYSIS

Do not attempt to create a fictitious "Boltz-SiteAF3."

Instead use Boltz-2 as an independent **ligand-conditioned structural and affinity evidence layer**.

Across the PAM panel, extract:

* recurring binding regions,
* recurring receptor contacts,
* pose clusters,
* pharmacophore conservation,
* affinity predictions,
* active/inactive differences.

Calculate residue-level contact frequencies where appropriate:

$$
CF(r)=
\frac{\text{number of valid predictions contacting residue }r}
{\text{number of valid predictions}}
$$

For active and inactive compounds separately calculate:

$$
\Delta CF(r)=CF_{active}(r)-CF_{inactive}(r)
$$

Use this to identify receptor residues preferentially associated with active PAM complexes.

Do not interpret Boltz-2 affinity as experimental potency.

Use affinity primarily as supporting/prioritization evidence.

# 6. CHEN et al. MEDICINAL-CHEMISTRY QC

Use:

**“A Medicinal Chemistry-Centered Evaluation of AlphaFold 3 and Boltz-2 Across Diverse Binding Modalities”**

as an additional medicinal-chemistry QC and evidence-weighting framework.

The paper emphasizes that allosteric, membrane-protein, and induced-proximity complexes remain challenging for AF3/Boltz-2 and that pharmacophore-level agreement can be more informative than whole-ligand RMSD.

Therefore explicitly stress-test the α9α10 predictions rather than treating high model confidence as proof.

Evaluate, where appropriate:

* ligand RMSD,
* pharmacophore RMSD,
* volume overlap,
* ligand-pocket occupancy,
* chemical validity,
* stereochemistry,
* bond geometry,
* ligand strain,
* protein–ligand clashes.

Because no experimental α9α10 PAM-bound structure exists, **do not claim experimental pose accuracy**.

Use these metrics for:

> **internal prediction consistency and medicinal-chemistry plausibility.**

# 12. ACTIVITY-CLIFF ANALYSIS

Identify the most informative small structural changes associated with large activity differences.

Ask:

> **Can the proposed binding site explain why a small chemical modification produces a large biological effect?**

Look for:

* lost hydrogen bonds,
* steric clashes,
* altered electrostatics,
* disrupted hydrophobic contacts,
* altered ligand orientation,
* conformational restrictions,
* changes in pocket occupancy.

Multiple independently explained activity cliffs should increase confidence in the proposed binding hypothesis.

# NON-NEGOTIABLE PRINCIPLE

Do not attempt to make the existing proposed binding site appear correct.

Treat it as a **falsifiable hypothesis**.

The strongest possible result is not:

> “All computational methods agree.”

The strongest result is:

> **Unbiased AF3/Boltz-2 predictions identify a recurring candidate site; SiteAF3 independently supports that site under site-conditioned modeling; the resulting binding mode passes structural and medicinal-chemistry QC; the model explains experimentally observed active/inactive SAR and activity cliffs; independent methods converge on specific receptor residues; and those residues generate experimentally testable predictions for mutagenesis.**

The final goal is therefore:

> **AF3/Boltz-2 discovery → SiteAF3 site-conditioned validation → medicinal-chemistry QC → experimental SAR validation → residue-level convergence → mutagenesis → experimental validation/falsification.**
